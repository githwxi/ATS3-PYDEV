# ATS3-PYDEV

For developing ATS3 in Python

## Project Description

The main delivery of the project consists of some functions
for exporting various internal syntax trees generated during the
compilation of ATS3 programs.

Also, the structure of this project can serve as a concrete example
for one interested in developing tools for ATS3 or based on it.

## What is ./xassets for?

The directory `./xassets` holds various files needed for this project.

- 1. For instance, the subdirectory `./xassets/ATS3` holds interface files
  (that is, SATS-files) for the ATS3/Xanadu implementation.

- 2. For instance, the subdirectory `./xassets/PY/xats2py` holds a library
  (of the name `lib2xatsopt_opt0.py`) that contains Python code for various
  functions constructed in the ATS3/Xanadu implementation. The word `lib2` indicates
  that the library is generated by the bootstrapped version of `xats2py`, and the
  word `xatsopt` means that the library is just for the core of ATS3/Xanadu (without
  extensions).

## What is `./srcgen1` for?
  This is the directory for the first trial (a.k.a., the first generation).
  Inside, there are subdirectories named `SATS`, `DATS`, and `HATS`. Also, there is
  `DATS/CATS` for storing non-ATS code (e.g., Python code).

  This are also subdirectories `TEST` (for testing) and `UTIL` (for building
  utility commands).
